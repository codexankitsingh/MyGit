# Contributing to mygit-lite

We welcome contributions!

## Development Setup

1. Fork and clone the repo.
2. `npm install`
3. Run tests: `npm test`

## Project Structure

- `bin/`: CLI entry point
- `lib/`: Core logic (Repo, Storage, Indexer, etc)
- `commands/`: CLI command implementations
- `tests/`: Unit and Integration tests

## Testing

Please add unit tests for new library functions and integration tests for new CLI commands.

## Code Style

Follow standard JavaScript/Node.js conventions.
